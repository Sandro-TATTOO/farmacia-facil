1. VISÃO GERAL DO ECOSSISTEMA
----------------------------------------------------------------

O projeto Farmácia Fácil é uma plataforma de saúde composta
por múltiplos aplicativos que se comunicam via Firebase.

  APP 1 — Usuário    farmacia.facio              ✅ PRODUÇÃO
  APP 2 — Vendedor   farmacia-facil-vendedor      ✅ PRODUÇÃO
  APP 3 — Entregador (não iniciado)               ⏳ Fase 3
  APP 4 — Admin      (não iniciado)               ⏳ Fase 4

Tags de backup no Git:

  v1.1-comunicacao          → Comunicação usuário-vendedor
  v2.0-fase2-completa       → OCR, pedidos, vendedor completo

5. FIREBASE — CONFIGURAÇÃO ATUAL
----------------------------------------------------------------

Projeto  : farmacia-facil-b980c
Console  : https://console.firebase.google.com
Conta    : sandroprogramatattoo@gmail.com
Plano    : Spark (gratuito)

Serviços ativos:
  ✅ Firebase Authentication — E-mail/senha
  ✅ Cloud Firestore — banco de dados
  ✅ GitHub Pages domain autorizado (ambos os apps)

Estrutura do Firestore:
  users/{uid}/
    name, email, phone, address, createdAt
    medications/{id}/
      name, dosage, times[], remainingPills, isActive...

  pharmacies/{uid}/
    name, ownerName, email, phone, address, city, state
    isApproved, isActive, hasDelivery, openingHours
    products/{id}/
      name, price, stock, category, requiresPrescription

  orders/{id}/
    userId, userName, pharmacyId, pharmacyName
    status (pending/confirmed/preparing/ready/delivering/
            delivered/cancelled)
    items[], totalPrice, deliveryAddress, isDelivery
    createdAt, updatedAt

Regras de segurança atuais:
  allow read, write: if request.auth != null;
  ⚠️ Qualquer usuário logado lê/escreve tudo
  ⚠️ Precisam ser refinadas antes do lançamento público

FONTES DE INFORMAÇÃO:
  1. Firestore em tempo real (remédios, pedidos, farmácias)
  2. Gemini API (quando funcionar — chave AQ. com problema 401)

O QUE O ASSISTENTE SABE RESPONDER:
  Sobre o usuário:
  - Remédios cadastrados, horários, dosagens
  - Alertas de estoque baixo
  - Status dos pedidos recentes
  - Farmácias disponíveis na plataforma

  Sobre saúde e emergências:
  - Procedimentos de primeiros socorros passo a passo
  - Queimaduras, convulsão, engasgamento, AVC, etc.
  - Números de emergência (SAMU 192, Bombeiros 193...)
  - Dicas de saúde e bem-estar
  - Orientação sobre medicamentos

  Sobre o app:
  - Como usar cada funcionalidade
  - Como ler uma receita pela câmera
  - Como fazer um pedido

AÇÕES QUE O ASSISTENTE PODE EXECUTAR:
  - Abrir discador (ligação SAMU em vermelho em emergências)
  - Navegar para qualquer tela do app
  - Ler receita pela câmera direto no chat
  - Narrar respostas por voz (TTS)

LIMITAÇÃO ATUAL:
  Chave AQ. (novo formato Google) retorna 401 via REST API.
  Soluções possíveis:
  a) Aguardar Google corrigir compatibilidade REST com AQ.
  b) Usar Firebase Vertex AI (integrado, sem chave separada)
  c) Usar Firebase Functions como proxy
  d) API ANVISA para dados de medicamentos em tempo real

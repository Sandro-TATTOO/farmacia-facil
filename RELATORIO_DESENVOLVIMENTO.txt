9. COMO RODAR O PROJETO LOCALMENTE
----------------------------------------------------------------

No terminal, dentro da pasta do projeto:

  Rodar no Chrome (Web):
    flutter run -d chrome

  Rodar no Android (com celular conectado via USB):
    flutter run -d android

  Compilar versão de produção Web:
    flutter build web --release --base-href "/farmacia-facil/"

  Enviar atualizações para o GitHub (deploy automático):
    git add .
    git commit -m "Descrição do que foi alterado"
    git push origin main

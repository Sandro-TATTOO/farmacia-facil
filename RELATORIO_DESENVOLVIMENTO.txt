----------------------------------------------------------------

AUTHENTICATION:
  Status    : Ativo
  Provedor  : E-mail/senha
  Usuários  : Cadastrados e funcionando
  Domínios  : github.io autorizado para ambos os apps

FIRESTORE — COLEÇÕES EXISTENTES:
  users/
    {uid}/ → name, email, phone, address, createdAt
      medications/ → remédios do usuário

  pharmacies/
    {uid}/ → dados completos + isApproved + isActive
      products/ → produtos cadastrados pelo vendedor

  orders/ → pedidos criados pelos usuários
    userId, pharmacyId, status, items[], totalPrice...

REGRAS DE SEGURANÇA ATUAIS:
  allow read, write: if request.auth != null;
  (qualquer usuário logado pode ler/escrever tudo)

  ⚠️ ATENÇÃO: Regras precisam ser refinadas antes
  do lançamento. Atualmente um usuário logado poderia
  modificar dados de outro usuário ou farmácia.

  REGRAS RECOMENDADAS PARA PRODUÇÃO:
  - users: só o próprio usuário lê/escreve seus dados
  - pharmacies: vendedor só edita sua própria farmácia
  - orders: usuário cria, vendedor atualiza status

6. FUNCIONALIDADE DE IA — SITUAÇÃO ATUAL E PRÓXIMOS PASSOS
----------------------------------------------------------------

SITUAÇÃO ATUAL — Leitura de Receita (OCR):
  Tecnologia : Google ML Kit (processamento local no dispositivo)
  Web        : Não funciona (ML Kit é nativo, não roda em browser)
  Android    : Instalado, seleciona imagem mas não retorna resultados

  CAUSA PROVÁVEL DO PROBLEMA:
  O filtro de extração de medicamentos é baseado em palavras-chave
  (mg, ml, comprimido, etc.) que podem não aparecer na mesma linha
  do nome do medicamento em muitas receitas. A IA de ler e entender
  o contexto está faltando.

PRÓXIMO PASSO — IA MAIS INTERATIVA:
  Para tornar a IA mais presente e funcional na aplicação,
  as possibilidades são:

  OPÇÃO A — Assistente Virtual no app (Chat IA):
  * Chat integrado na Home ou como aba separada
  * Usuário pergunta "Qual horário devo tomar Amoxicilina?"
  * IA responde com base nos remédios cadastrados
  * Pode sugerir compras, alertar sobre interações
  * Tecnologia: Firebase Vertex AI (nativo no Firebase)
    ou OpenAI API

  OPÇÃO B — IA para melhorar o OCR da Receita:
  * Em vez de regras fixas, usar IA para entender o texto
  * Mais precisa para diferentes tipos de receita
  * Tecnologia: Firebase Vertex AI (usa conta Google que já temos)

  OPÇÃO C — Recomendação Inteligente:
  * IA sugere farmácias com base no histórico de pedidos
  * IA alerta sobre remédios que costumam acabar em determinado dia
  * IA sugere compra antes de acabar
  * Tecnologia: lógica local + Firestore (sem API externa)

  OPÇÃO D — Processamento de Receita via Firebase Functions:
  * Usuário envia foto → Firebase Function processa com Vertex AI
  * Resultado retorna para o app
  * Não depende de chave de API no client
  * Mais seguro e escalável

  RECOMENDAÇÃO: Combinar B + D para resolver o OCR da receita
  de forma robusta, e depois implementar A como assistente virtual.
